# UI 명세

기준일: 2026-09-15. 현재 Unreal의 팝업과 요약 HUD를 설명하는 기준 문서입니다. 구현은 저장된 Blueprint Canvas HUD이며, Python은 제작·재생성에만 사용합니다. 게임 규칙은 [GAMEPLAY.md](GAMEPLAY.md), 최신 검증 상태는 [검증 색인](../Validation/VALIDATION.md)에서 구분해 관리합니다.

## 화면과 작성 기준

[layout.py](../../Content/Python/jonggu/ui/layout.py)의 `BUTTONS`·`resolve_rect`·`button_rect_expr`가 표시·클릭·가림 영역의 공통 기준입니다. 수치는 **1280×720의 카메라 영역** 기준 `(x, y, 너비, 높이)`입니다. 다른 창 크기에서는 실제 Canvas에 맞춰 비례 표시합니다. 포인터는 [controller.py](../../Content/Python/jonggu/world/controller.py)에서 16:9 카메라 바깥의 검은 여백을 제외하고 같은 좌표로 변환합니다.

Unity Hub의 실제 저장 화면에서 이어받은 픽셀 분위기를 사용합니다. 일반 HUD는 갈색 패널·코인·음식 그림, 팝업은 베이지 프레임과 종이 카드를 사용합니다. 현재 이미지·글꼴 원본과 대상은 [assets.py](../../Content/Python/jonggu/ui/assets.py), 정식 에셋 경로는 [중앙 에셋 목록](../../Content/Python/jonggu/assets.py)이 기준입니다. 글꼴과 라이선스는 [SourceAssets/Fonts](../../SourceAssets/Fonts/)에 있습니다.

- 글꼴: Galmuri11 Regular/Bold. 팝업 제목 32px, 본문 22px, 보조 18px. HUD 주요 수치 22px, 일반 정보·말풍선 18px.
- 팝업: 베이지 `#C4AF86`, 종이 `#F3ECDB`, 글자 `#1F1F1F`, 금색 `#E6CB87`, 주요 버튼 녹색 `#37583E`.
- HUD: 갈색 `#3D260D`, 밝은 글자 `#F3ECDB`, 강조 `#FFEDA1`. 버튼은 메뉴 노랑·유입 조절 녹색·마감 베이지로 구분합니다.
- 프레임: 원본 32×32의 8px 모서리를 유지하는 9분할. 안내 상자는 34×34 원본을 사용합니다. X는 원본의 투명 여백을 제외해 표시하고 클릭 영역은 40×40입니다.

## 팝업

[panels.py](../../Content/Python/jonggu/ui/panels.py)가 화면 내용을, [primitives.py](../../Content/Python/jonggu/ui/primitives.py)가 공통 버튼·프레임·텍스트를 만듭니다. 팝업은 월드와 일반 HUD 위에 검정 52% 암막을 그리고, 내부 기본 여백은 32px입니다.

| 화면 ID | 화면 / 영역 | 표시와 주요 동작 ID |
|---|---|---|
| 1 | 메뉴 `(80, 92, 1120, 536)` | 메뉴 카드 `101~103`, 손님 수 `104·105`, 영업 시작 `106`, X `107` |
| 2 | 팬 `(80, 92, 1120, 536)` | 음식 조리 `201·202`, 완성품 비우기 `203`, X `204` |
| 3 | 냄비 `(80, 92, 1120, 536)` | 기본·특선 조리 `211·212`, 완성품 비우기 `213`, X `214` |
| 4 | 일시정지 `(300, 164, 680, 392)` | 계속 `301`, 영업 재시도 `302`, 이전 화면으로 돌아가는 X `303` |
| 5 | 결산 `(220, 110, 840, 500)` | 다음 날 준비 `401`. 직접 닫는 X는 없음 |

메뉴 창은 선택된 카드를 체크와 색으로 구별합니다. 오른쪽에 손님 수 선택, 선택 메뉴 이름, 팬 공유 또는 팬·냄비 분산 사용, 조개 수를 함께 표시합니다. 조리 창은 음식 그림·이름·시간·수량·조개 비용과 실제 기구 상태·진행률·완성 수량을 표시하며, 팬과 냄비 모두 조개 수를 보여 줍니다. 음식명과 시간·수량은 [요리 정의](../../Content/Python/jonggu/gameplay/data.py)를 사용합니다.

활성 버튼은 마우스를 올리거나 누르면 밝기와 테두리가 바뀝니다. 비활성 조리 카드는 흐리게 표시하고 메뉴 미선택·기구 사용 중·조개 부족 등의 사유를 안내합니다. 비활성 버튼은 클릭해도 동작하지 않으며, 한 번의 클릭이 새로 열린 화면까지 전달되지 않습니다. 조리는 음식 카드를 한 번 눌러 시작하고 안내·오류는 팝업 안에 표시합니다.

모든 팝업은 이동 입력을 차단합니다. **조리 선택창은 영업 시간을 멈추지 않으며, 일시정지만 전체 시간을 멈춥니다.** `Esc` 또는 `F10`은 현재 화면을 기억하고 일시정지를 열거나 이전 화면으로 돌아갑니다. 계속하기와 일시정지 X도 같은 복귀를 사용합니다. 재시도 버튼은 영업 중에만 표시합니다. 창을 닫으면 해당 화면에 맞게 이동 차단을 다시 설정합니다. 에디터 Play 종료 키는 [프로젝트 설정](../../Config/DefaultEditorSettings.ini)의 `Shift+Esc`입니다.

## 일반 HUD와 접기

일반 화면은 ID `0`입니다. [renderer.py](../../Content/Python/jonggu/ui/renderer.py)는 화면 중심을 비워 두고 가장자리에 아래 그룹을 표시합니다.

| 그룹 | 영역 | 정보와 접기 동작 |
|---|---|---|
| 날짜·상태 | `(20, 20, 340, 44)` | 날짜, 준비·해변·영업·유입 중단·마감 정리 |
| 누적 매출 | `(964, 20, 296, 44)` | 코인과 현재까지의 매출 |
| 주문 | `(984, 96, 276, 104/284)` | 영업 중 표시. 요약은 두 좌석의 그림·대기시간과 접수/서빙 수, 상세는 음식 이름을 추가. 동작 `31` |
| 기구 | `x=20`, 너비 `284`, 높이 `116/260`, 아래 끝 `y=684` | 영업 중 표시. 요약은 그림·조리 중/완성 수량·특선, 상세는 이름·남은 시간·진행률 추가. 동작 `32` |
| 소지품 | `x=984`, 너비 `276`, 높이 `80/164` | 영업 중에는 주문 아래 12px 간격, 그 외 `y=96`. 조개·든 음식·특선을 표시. 동작 `33` |
| 중앙 안내 | `(336, 600, 624, 40)` | 근처 대상 안내 또는 일시적 알림. **둘 다 없으면 숨김** |
| 영업 조작 | `(336, 652, 624, 56)` | 준비 메뉴 `10`, 유입 중단/재개 `20`, 마감 `21`. 해변·마감 중에는 비어 있는 배경도 숨김 |
| 일시정지 | `(984, 652, 276, 56)` | 일시정지 버튼 `30` |

높이의 앞 값은 요약, 뒤 값은 상세입니다. 요약 카드 전체를 클릭하면 펼쳐지고, 상세 카드의 위쪽 40px 제목 줄을 클릭하면 접힙니다. 화살표 방향으로 상태를 구별합니다. `hud_expanded_mask`의 주문·기구·소지품 비트는 `1·2·4`이며 같은 Play의 맵 이동·재시도·다음 날에는 유지됩니다. 저장 파일에는 포함하지 않아 새 Play에서는 모두 요약 상태로 시작합니다.

일반 HUD 버튼은 팝업 뒤에서 입력을 받지 않습니다. `WASD 이동 · E 상호작용` 안내와 기존 월드의 E 표시는 유지합니다. E 자체를 새 말풍선으로 바꾸지는 않습니다.

## 기구 위 진행 말풍선

팬·냄비의 실제 대상 위치에 **Z+240cm**를 더한 앵커를 화면에 투영합니다. 말풍선 본체는 **72×40px**, 꼬리는 **8px**, 왼쪽 위는 투영 좌표에서 `(-36, -48)`입니다. 영업 중 점유된 기구에 표시하고, 해변·결산·빈 기구·유효하지 않거나 화면 밖인 앵커에서는 숨깁니다.

조리 중에는 남은 초를 올림해 표시하고 내부 `(8, 28, 56, 6)` 진행바를 금색 `#E6CB87`로 그립니다. `남은 시간 ≤ 0`이고 `완성품 수량 > 0`일 때 완료 수량을 표시하며 진행바는 녹색 `#8ACC40`이 됩니다. 일반·특선 모두 실제 기구 데이터를 사용합니다. 말풍선은 정보 표시용이며 별도 클릭 동작은 없습니다.

## 플레이어 가림과 투명도

[visibility.py](../../Content/Python/jonggu/ui/visibility.py)는 충돌체만이 아니라 머리·몸·발 그림을 포함한 플레이어 Actor Bounds의 여덟 꼭짓점을 투영합니다. 화면 상대 좌표는 실제 Canvas 크기로 정규화하며 검은 여백을 중복으로 빼지 않습니다.

플레이어 영역에 **20px 여유**를 더했을 때 겹친 그룹만 **0.15초** 전환으로 배경·프레임은 기본 불투명도의 **20%**, 글자·그림·진행바는 **65%**까지 낮춥니다. 이미 겹친 그룹은 **32px 여유** 밖으로 벗어났을 때 **0.25초**에 걸쳐 복원합니다. 마우스를 올리면 같은 복원 속도로 선명해지며 영역·배치·클릭 판정은 바뀌지 않습니다.

대상은 위 8개 HUD 그룹과 두 기구 말풍선, 총 10개 그룹입니다. 팝업에서는 일반 HUD 투명도를 즉시 정상화한 뒤 공통 암막을 적용합니다. 유효한 플레이어·Canvas 정보가 없을 때도 정상 불투명도로 표시합니다. 투명도 보간은 게임의 프레임 시간을 사용하며, 일시정지 창에서도 위의 즉시 정상화 규칙을 적용합니다.

## 데이터와 유지보수

[contracts.py](../../Content/Python/jonggu/ui/contracts.py)의 `HUD_FIELDS`는 표시용 계약입니다. [presentation.py](../../Content/Python/jonggu/gameplay/presentation.py)가 실제 주문·기구·접시·세션 상태를 전달하고, [input.py](../../Content/Python/jonggu/gameplay/input.py)가 활성 여부·공유 클릭 영역·화면 전환을 처리합니다. HUD는 직접 재고나 영업 기록을 바꾸지 않습니다.

빈손·빈 기구·비활성 주문의 음식 ID는 `-1`로 전달해 지난 그림이 남지 않게 합니다. 표시 매출은 영업 중에만 누적 매출에 현재 영업 수입을 더하고 결산 뒤에는 확정 누적값을 사용합니다. 결산 창에는 서빙 수, 기본 매출과 추가 보상, 조개 사용량, 특선 제공 수, 누적 매출을 구분해 표시합니다.

화면 변경은 해당 제작 소스에서 수정하고 [제작 절차](../Development/AUTHORING.md)에 따라 재생성합니다. [hud.py](../../Content/Python/jonggu/ui/hud.py)는 빌드 진입점이고 [theme.py](../../Content/Python/jonggu/ui/theme.py)는 색 변환·9분할 계산을 담당합니다. 새 검증 결과는 [검증 색인](../Validation/VALIDATION.md)에 연결합니다. 이 문서 정리 자체는 엔진 재검증이나 수동 플레이 완료를 뜻하지 않습니다.
