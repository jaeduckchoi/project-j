# 첫 프로토타입 플레이 관찰

목적은 메뉴·기구 조합과 주문량 조절이 플레이어의 선택을 만드는지 확인하는 것입니다. **자동 생산 측정은 완료했으며 사람의 조작감·재미·선택 이유는 아직 관찰하지 않았습니다.** 아래 측정 결과와 미실시 절차를 구분해 기록합니다. 현재 기능 상태는 [검증 인덱스](VALIDATION.md)에 있습니다.

## 자동으로 측정한 생산 동작

최신 재현 기록은 **2026-09-14 23:56:49 KST**의 [PIE 실험 기록](../../Saved/RefactorQA/pie_report.json)에 있는 `experiments`입니다. 검증 소스는 [verify_experiments.py](../../Content/Python/jonggu/validation/verify_experiments.py)입니다. 실제 컴파일된 Blueprint 함수를 1초 간격으로 진행했고, 모든 조건은 조개 1개로 시작했습니다. 손님 유입을 중단한 생산 비교이며 접시 수령·폐기의 소요시간은 0초로 두었습니다. 이동과 손님 서빙은 측정하지 않았습니다. `Saved/` 보고서는 선택적 로컬 증거이므로 새 클론에는 없을 수 있습니다. 이번 문서 정리에서 실험을 재실행하지 않았습니다.

| 조건 | 확인한 동작 | 두 그릇 완성 시각 |
|---|---|---:|
| 볶음밥 + 김치전 / 팬 공유 | 0초에는 한 메뉴만 시작; 두 번째는 기구를 8초 기다림; 각 접시 8초·20초 완성 | 20초 |
| 볶음밥 + 기본 찌개 / 팬·냄비 분산 | 두 메뉴를 0초에 동시에 시작; 각 접시 8초·16초 완성 | 16초 |
| 기본 찌개 두 번 | 조리 시작 2회, 조개 사용 없음 | 32초 |
| 특선 찌개 한 번 | 조리 시작 1회, 조개 1개로 두 그릇 | 16초 |

메뉴 비교의 4초 차이는 서로 다른 요리와 조리 시간을 포함합니다. 기구 분산만의 인과 효과로 해석하지 않습니다. 특선의 시작 횟수·완성시간 차이도 실제 이동 부담, 매출 증가 또는 재미가 확인되었다는 뜻은 아닙니다.

## 수동 플레이 비교 절차 — 미실시

공통 조건: 같은 맵·이동 속도·조리 수치, 손님 4명, 시작 조개 1개와 동일한 개점 직전 상태를 사용합니다. 각 조건 전에 그 상태를 복원합니다. 먼저 조작만 짧게 연습한 뒤, 측정 중에는 진행자가 조리 순서를 알려주지 않습니다. 4명 모두 대접하되 선조리와 손님 유입 중단·재개는 자유롭게 둡니다. 실제 이동·수령·서빙 시간은 포함하고, 개인 휴식은 기록에서 구분합니다.

- **비교 1 — 메뉴 조합:** A는 볶음밥+김치전, B는 볶음밥+기본 찌개입니다. 두 조건 모두 조개를 사용하지 않습니다. 팬을 기다리는 동안 한 행동, 두 기구를 번갈아 확인한 행동, 유입 조절 시점과 이유를 기록합니다.
- **비교 2 — 조개 사용:** C와 D 모두 김치찌개만 판매합니다. C는 기본 조리만 하고, D는 특선 한 번을 원하는 시점에 사용한 뒤 기본 조리를 계속합니다. 두 그릇의 수령·서빙 순서와 남은 완성품이 다음 행동에 미친 영향을 기록합니다.

순서 효과를 줄이기 위해 첫 참가자는 A→B, C→D로, 다음 참가자는 B→A, D→C로 진행합니다. 한 명만 참여하면 다른 회차에서 반대 순서를 반복하고, 연습 효과를 한계로 남깁니다. 비교 영업 중 해변에 가지 않습니다. 조개를 찾으러 갈 의향은 아래 질문으로 확인하며 실제 탐험 선택을 관찰한 결과와 구분합니다.

각 영업이 끝난 직후 다음 세 질문을 같은 문장으로 묻습니다.

1. 같은 조건으로 다시 영업한다면 어떤 메뉴를 선택하겠어요? 그 이유는 무엇인가요?
2. 다음 날 조개를 찾으러 가고 싶나요? 그 이유는 무엇인가요?
3. 손님 받기를 멈추거나 다시 시작한 시점은 언제였나요? 그렇게 결정한 이유는 무엇인가요? 사용하지 않았다면 그 이유는 무엇인가요?

## 관찰 기록 — 아직 수행하지 않음

아래 행은 작성 전 빈 양식입니다. 사람의 재미·선택 이유·탐험 동기는 아직 검증하지 않았습니다. 실제로 본 행동과 참가자의 말을 구분하고, 인용은 들은 표현 그대로 남깁니다.

|---|---|---|---|---|
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

완료시간이 짧다는 이유만으로 더 재미있다고 판정하지 않습니다. 참가자가 스스로 조리 순서를 바꾸거나 유입을 조절했는지, 그 결정을 설명할 수 있는지를 시간·주관적 선호와 함께 읽습니다. 이전 보고서에서 이번 범위에 선택하지 않은 성장·물때·추가 재료·수동 조리·관계 등의 제안은 후속 가설로 유지하며, 이 관찰만으로 구현 범위를 확대하지 않습니다.
