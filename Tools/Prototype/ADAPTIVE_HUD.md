# 요약 HUD와 조리 진행 말풍선

일반 HUD는 주문·기구·소지품을 각각 요약 상태로 표시합니다. 카드를 클릭해 펼치고 상세 제목 줄을 클릭해 접습니다. 접기 상태는 GameInstance의 UI 전용 필드 `hud_expanded_mask`에 보관하여 같은 Play 안에서 맵 이동·재시도·다음 날 전환을 따라갑니다. 이 값은 게임 저장 파일에 포함하지 않으며 새 Play에서는 0으로 시작합니다.

## 화면과 입력

`hud_layout.py`의 공유 영역이 표시·클릭·가림 검사의 기준입니다. 주문은 우측 위에, 소지품은 주문 아래에 놓이며, 기구는 좌측 아래에 바닥을 고정합니다. 요약 기구에는 음식 아이콘·조리 중 상태·완성 수량을 남기고 상세 상태에서 시간·진행률을 표시합니다. 빈 영업 버튼 배경과 내용 없는 중앙 안내는 숨깁니다.

각 기구 위에는 72×40px 본체와 8px 꼬리의 픽셀 말풍선을 표시합니다. 조리 중에는 남은 초와 56×6px 진행바를, 완료 후에는 남은 그릇 수를 표시합니다. 일반/특선 모두 실제 관리자 데이터를 사용하며 `남은 시간 ≤ 0 && 완성품 수량 > 0`일 때만 완성으로 표시합니다. 말풍선은 실제 기구 위치에 Z+240cm를 더한 앵커를 투영합니다. E 표시는 기존 그대로입니다.

## 가림과 투명도

`build_hud_visibility.py`는 플레이어 전체 Actor Bounds의 여덟 꼭짓점을 화면에 투영합니다. 충돌체만 사용하거나 걷기용 머리·몸·발 Sprite를 누락하지 않습니다. `ProjectWorldToScreen`의 플레이어 뷰포트 상대 좌표를 HUD의 실제 Canvas 크기로 나누며, 이미 제거된 검은 여백을 다시 빼지 않습니다.

20px 여유를 포함한 플레이어 영역과 겹친 그룹만 0.15초 동안 배경·프레임 20%, 글자·아이콘·진행률 65%로 바뀝니다. 여유 32px 영역에서도 벗어나면 0.25초 동안 복원합니다. 마우스를 올린 그룹은 선명해지며 투명도는 클릭 판정이나 배치를 바꾸지 않습니다. 모달 화면에서는 일반 HUD 투명화를 초기화하고 기존 52% 암막을 적용합니다. 유효한 플레이어·Canvas 정보가 없으면 정상 불투명도로 표시합니다.

## 검증

2026-09-14에 Blueprint 재생성·컴파일·두 맵 구성을 완료했습니다. 저장 19개, 기존 영업·팝업·순환 120개, 메인 HUD 7개, 새 HUD 런타임 12개, 접기 상태의 이동·재시도·다음 날·새 Play 6개 등 **기능 검사 164개를 통과**했습니다.

1280×720, 1920×1080, 1189×862의 실제 PIE에서 기본 상태 54장과 그룹별 가림·복원 49장, **총 103장의 원본 PNG**를 기록했습니다. 요약·상세·혼합, 두 기구 동시 조리, 서로 다른 완료 시점, 특선 2→1→0그릇, 비우기, 머리·몸·발 겹침, 경계 여유, 호버·투명 상태 클릭, 팝업·전체 일시정지, 해변을 확인했습니다. 모든 10개 그룹의 실제 Blueprint 투명화 값이 가림 시 1, 복원 시 0에 도달함을 확인했습니다. 추가 49장에는 반복 상태·해상도별 검사 388회가 포함되며 서로 다른 기능 388개를 뜻하지 않습니다.

기존 영업 HUD 패널 면적 289,536px²에서 요약 HUD 최대 193,984px²로 **33.0% 감소**했습니다. 새 면적은 두 조리 말풍선과 일시적인 중앙 안내까지 포함합니다. 한글·선택 화살표·진행바·완료 수량·플레이어가 말풍선 뒤로 비치는 모습은 원본 PNG로 확인했습니다.

원본 플레이어·GameMode 자산의 SHA256과 저장 필드·스키마는 기존과 같습니다. 검증용 슬롯만 사용하고 사용자 저장 및 에디터 창 설정을 보존했습니다. 화면 캡처는 재현성을 위해 영업 Tick을 고정했으며, 조리 시간 진행·전체 일시정지는 별도 실제 Blueprint·엔진 시간 검사로 확인했습니다. 전환 시간 0.15/0.25초는 코드와 프레임 표본으로 확인했지만 정확한 소요 시간을 수치 판정하지 않았습니다.
